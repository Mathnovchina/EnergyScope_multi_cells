## Navigation

`VTT_272_reference_properties.csv` transcribes selected reference values, not adopted parameter values. Printed page numbers and PDF page numbers are separate columns. The report's printed page 62 is PDF page 63.

- LHV/NCV = lower/net calorific value; HHV/GCV = higher/gross calorific value.
- `dry_total` includes ash/inorganic matter, unlike dry ash-free or organic-only mass.
- Basic density is oven-dry mass per green solid volume, not wet bulk mass per loose chip volume.
- Do not multiply an as-received LHV by dry tonnes, or a solid-volume density by loose chip volume.
- Black-liquor rows in this CSV are **HHV**, not LHV. S2BIOM's organic wood-derived residue estimate has not been reconciled with VTT's total liquor solids.
