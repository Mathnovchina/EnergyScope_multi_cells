## 3. Model Mechanics — Key Points Understood Today

### HVC and Non-Energy Demand
HVC (High-Value Chemicals) is a sub-category of `NON_ENERGY` demand. The constraint in `ESMC_model_AMPL.mod` (line 285–286):
```ampl
else (if l == "HVC" then
    end_uses_input[c,"NON_ENERGY"] * share_ned[c,"HVC"] / total_time
```
Only the **HVC fraction** of NON_ENERGY feeds the HVC layer. The rest of NON_ENERGY is split between AMMONIA and METHANOL via their own `share_ned` entries. The sum of `share_ned[HVC] + share_ned[AMMONIA] + share_ned[METHANOL] = 1` by construction.

Technologies `OIL_TO_HVC` and `GAS_TO_HVC` produce HVC as a co-product alongside heat and electricity (via `layers_in_out`).

### Import/Export Architecture (single-cell)
- **All external imports**: `R_t_exterior[FI, i, h, td]`, capped by `avail_exterior[FI,i]`
- **Electricity import cap**: 25,000 GWh/y (≈ 25 TWh), set in the baseline patch CSV
- **Fossil fuels**: `avail_exterior = 1e15` (uncapped), penalised via `c_op_exterior` and `gwp_op_exterior`
- **Exports**: not modelled in single-cell (no neighbouring cell inside `REGIONS`)
- **`R_t_exterior` cost**: 83.3 €/MWh for electricity, uniform regardless of actual origin country

## 4. Multi-Cell Extension — Analysis and Decision

### What is ready
All data is available for a **FI + SE + EE** 3-cell run:
- Country-level data folders: `Data/2035/FI/`, `Data/2035/SE/`, `Data/2035/EE/` (and 2050)
- Pre-defined interconnects in `Data/2035/01_EXCH/Network_exchanges.csv`:

| Link | Resource | Network type | tc_min / tc_max | Distance |
|------|----------|-------------|-----------------|----------|
| FI ↔ SE | ELECTRICITY | HVDC_SUBSEA | 2.4 / 4.9 GW | 532 km |
| FI ↔ EE | ELECTRICITY | HVDC_SUBSEA | 1.0 / 1.7 GW | 618 km |
| FI ↔ SE | GAS | GAS_SUBSEA | 0 / 20 GW | 532 km |
| FI ↔ EE | GAS | GAS_SUBSEA | 3.75 / 20 GW | 618 km |
| FI ↔ EE | H2 | H2_SUBSEA_RETRO/NEW | 0 / 13 GW | 618 km |
| FI ↔ SE | H2 | H2_SUBSEA_NEW | 0 / 13 GW | 532 km |

- NO (Norway) has data but **no interconnect entry** — needs manual addition to `Dist.csv` and `Network_exchanges.csv` if wanted.

### What multi-cell changes
- The 25 TWh/y electricity import cap is replaced by endogenous hourly trade on HVDC links
- `R_t_exterior` shrinks to imports from outside the 3-cell model (RU, global gas/oil)
- Each country gets its own GWP constraint and optimises jointly with neighbour costs
- The `Exch_imp/Exch_exp` variables activate automatically when `REGIONS = {FI, SE, EE}`

### Decision
Build `scripts/run_fi_nordic_3c.py` (FI + SE + EE, 2035 and 2050). See next steps.
